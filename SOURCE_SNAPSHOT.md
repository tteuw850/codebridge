# Snapshot do CodeBridge 2.0.12-prealpha

Esta versao foi obtida a partir da instalacao local do CodeBridge no Windows em novembro de 2026.

Incluidos:
- Codigo-fonte Python (app_rewrite, author_mcp, rag, installer)
- Extensao de navegador e recursos visuais
- Documentacao, requirements e metadados da versao

Nao incluidos:
- Runtime Python embarcado, executaveis e bibliotecas de terceiros
- Bancos de dados, indices, modelos de IA, caches ou sessoes locais
- Segredos, tokens, arquivos .env e configuracoes individuais

A instalacao local nao possui historico Git original. Este commit e um snapshot de codigo, nao um pacote instalador autossuficiente. O uso em outra maquina pode exigir dependencias e configuracao do ambiente.
